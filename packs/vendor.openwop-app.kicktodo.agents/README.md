# vendor.openwop-app.kicktodo.agents

## Full description

_Moved from `pack.json` `description`, which the v2 manifest schema caps at 1024 characters._

KickTodo specialist-skill pack (ADR 0414 P4; PRD §8.5) — mostly HANDOFF workers, not named agents: bounded task-scoped skills KickBot and the KickTodo workflows invoke. Scratchpad-only memory, typed task/return contracts, tool-allowlisted to the registered read tools; domain writes always pass through governed nodes/surfaces. ONE roster-bound EXCEPTION (ADR 0458): `challenge-author` (Challenge Author) is a named conversational agent the creator talks to in the ONE chat to drive the Challenge Factory — it carries per-run conversation memory and its own action tools, not the handoff task/return contract. The persistent named KickBot instance is a roster/profile agent provisioned by the host (kickbotService) — NOT defined here. v1.5.0 (ADR 0458 P2): the three simulation personas (Sim: Newcomer/Time-poor/Skeptic) return a typed closed-world verdict via `schemas/sim-verdict.schema.json` — the factory's evaluation stage reads a structured pass/flag/block, never free prose it must re-parse. v1.6.0 (ADR 0459 P1): the `replan-composer` HANDOFF skill turns a participant's stated intent into a typed closed-world plan revision via `schemas/plan-revision.schema.json`, composed ONLY from the ADR 0429 lanes (schedule / publisher-declared substitution / recovery) grounded in the real state it reads with its two READ tools — it commits nothing; the replan builtin validates it and the participant approves it at their own gate. v1.7.0 (ADR 0463): `plan-revision.schema.json` gains an OPTIONAL `clarification` arm (ASK XOR ACT) — when the intent falls in the ADR 0429 lanes but is under-specified, the composer returns EMPTY `commands` PLUS a structured `clarification` ({ question, field: a day-1-catalog select/date, pendingCommand shell }) so the replan builtin can raise a single A2UI clarification form in the participant's own conversation and fold the answer into the pending command, instead of the composer guessing.
